## Printing in Python ##

Printing in Python is a fundamental operation that allows you to output text or variables to the console. Here's a simple example:

```python
# A function that prints a greeting
def print_greeting():
    print("Hello, World!")

# Call the function to see the output
print_greeting()
```

In this example, we define a function called `print_greeting()` that uses the `print()` function to output the string "Hello, World!" to the console. When you call this function, it will display the greeting.

The `print()` function is versatile and can handle various data types, including strings, numbers, and even complex objects. It automatically adds a newline character at the end of the output by default.
