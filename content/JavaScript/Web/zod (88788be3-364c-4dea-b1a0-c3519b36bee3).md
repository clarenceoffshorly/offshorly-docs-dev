# zod validation #

zod is a TypeScript-first schema declaration and validation library.

[read more](https://zod.dev/)

Here's an example of how to use zod for basic string validation:

```js
import { z } from 'zod'

// Creating a schema for strings
const stringSchema = z.string()

// Parsing
stringSchema.parse('tuna') // => "tuna"
stringSchema.parse(12) // => throws ZodError

// "Safe" parsing (doesn't throw error if validation fails)
stringSchema.safeParse('tuna') // => { success: true; data: "tuna" }
stringSchema.safeParse(12) // => { success: false; error: ZodError }
```

We can define the schema as an object like this:

```js
// All properties are required by default
const Dog = z.object({
  name: z.string(),
  age: z.number(),
})

// Extract the inferred type like this
type Dog = z.infer<typeof Dog>

// Equivalent to:
type Dog = {
  name: string
  age: number
}
```

This example demonstrates how to create object schemas and infer TypeScript types from them using zod.
