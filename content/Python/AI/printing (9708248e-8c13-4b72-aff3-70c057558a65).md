## Printing in Python ##

Printing in Python is a fundamental operation that allows you to output text or variables to the console. Here's a simple example:

```python
# A function that prints a greeting
def just_a_print():
    print("Hello, World!")

# Call the function to see the output
just_a_print()
```

In this example:

1. We define a function called `just_a_print()`.
2. Inside the function, we use the `print()` function to output the string "Hello, World!".
3. To see the output, you would need to call the function.

Remember, you can print various data types in Python, including strings, numbers, and even variables.
