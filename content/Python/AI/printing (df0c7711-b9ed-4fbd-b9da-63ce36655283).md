This document provides a guide on how to use the print function in Python.

## Printing in Python ##

Printing is a fundamental operation in Python, used to display output to the console. Here's a simple example of how to use the `print()` function:

```python
# A function that demonstrates a basic print operation
def just_a_print():
    print("Hello, World!")

# Call the function to see the output
just_a_print()
```

In this example:

1. We define a function called `just_a_print()`.
2. Inside the function, we use the `print()` function to output the string "Hello, World!".
3. To see the result, you would need to call the function.

When you run this code, it will output:

```
Hello, World!
```

This is a basic example of printing in Python. The `print()` function can be used with various data types and has additional parameters for formatting output.
